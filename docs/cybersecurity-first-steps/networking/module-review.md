# Practice Challenge

Look around your home.

Choose five network-connected devices.

For each one, answer:

- Does it use Wi-Fi or Ethernet?
- Does it have an IP address?
- Does it communicate with the Internet?
- What might it use the network for?

You don't need exact technical answers.

Focus on thinking through how the devices communicate.
