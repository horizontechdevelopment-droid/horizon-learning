# Understanding Networks

Welcome!

You've completed three major milestones.

You know how to start Kali Linux.

You know your way around Linux.

Now it's time to understand how computers communicate.

This module introduces networking concepts that every cybersecurity learner should understand.

Don't worry if networking seems confusing.

We'll build your understanding one idea at a time.

---

# What You'll Learn

In this module you'll learn:

- What a network actually is.
- How devices communicate.
- The difference between Wi-Fi and Ethernet.
- What an IP address is.
- Why ports exist.
- How computers find each other.
- How your own home network works.

---

# Why This Matters

Nearly every cybersecurity tool depends on networking.

Before using tools like Nmap and Wireshark, you need to understand what they're actually showing you.

Think of this module as learning the roads before learning to drive.

---

!!! note "Progress, Not Perfection"

    Networking can feel overwhelming at first.

    That's completely normal.

    We'll focus on understanding concepts instead of memorizing technical details.
