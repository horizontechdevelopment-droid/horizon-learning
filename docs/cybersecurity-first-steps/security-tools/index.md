# Your First Security Tools

Welcome!

You've built a strong foundation.

You understand Linux.

You understand networking.

Now it's finally time to explore some of the tools that make Kali Linux unique.

Before we begin, remember something important:

Tools don't make someone good at cybersecurity.

Understanding does.

These tools simply help us observe and understand computer systems and networks.

Throughout this module, you'll only use tools in safe, ethical, and responsible ways.

---

# What You'll Learn

In this module you'll learn:

- Why Kali includes so many tools.
- What Nmap is designed to do.
- What Wireshark is used for.
- How to safely explore your own network.
- How to document what you discover.

---

# Why This Matters

Cybersecurity tools don't magically find problems.

They collect information.

Your understanding allows you to interpret that information correctly.

The stronger your foundation, the more valuable these tools become.

---

!!! note "Progress, Not Perfection"

    You are not expected to become an expert in Nmap or Wireshark during this module.

    The goal is simply to become comfortable with what these tools are, what they do, and how to use them responsibly.

# By the End of This Module

You'll be able to:

- Explain the purpose of several common cybersecurity tools.
- Understand what Nmap and Wireshark are designed to do.
- Safely examine your own network.
- Begin documenting your observations.
- Continue learning with confidence.

---

# Ethics First

Cybersecurity is built on trust.

Only use the techniques and tools you learn in this course on:

- Systems you own
- Systems you have explicit permission to test
- Authorized learning environments

Never assume permission.

Always ask first.
