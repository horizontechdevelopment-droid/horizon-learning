# What You Learned

During this module you learned how to:

- Use the Linux terminal.
- Understand prompts and command output.
- Navigate directories.
- Understand files and folders.
- Use common Linux commands.
- Find trustworthy documentation.
- Create, move, copy, rename, and remove files.
- Understand why Linux uses permissions.

Those are foundational Linux skills used by professionals every day.

# Practice Challenge

Without looking at previous lessons, try completing this exercise.

Create a directory named:

    practice

Move into it.

Create two files.

Copy one of them.

Rename the copy.

List the directory.

Delete the copied file.

Return to your home directory.

Remove the practice directory.

Don't worry if you need to look up commands.

Knowing where to find the answer is part of learning.
