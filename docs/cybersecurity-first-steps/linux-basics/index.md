# Learning Your Way Around Linux

Welcome!

You've successfully started Kali Linux and explored the desktop.

That is a bigger accomplishment than many people realize.

Now it's time to become comfortable using Linux itself.

Don't worry—you are **not** expected to memorize dozens of commands.

Our goal is much simpler:

**Understand how Linux works and become confident using it.**

---

## What You'll Learn

In this module you will learn how to:

- Use the terminal with confidence.
- Navigate the Linux file system.
- Understand where your files are stored.
- Find help when you need it.
- Work safely with files and directories.
- Understand why Linux permissions exist.

---

## Why This Matters

Almost every cybersecurity tool assumes you're comfortable using Linux.

The better you understand Linux, the easier every future lesson will become.

Think of this module as learning the language before trying to write a novel.

---

!!! note "Progress, Not Perfection"

    You do **not** need to memorize every command.

    Professional Linux users regularly look up commands and documentation.

    Your goal is to understand what commands do and know when to use them.

---

## Module Roadmap

In this module you'll complete:

1. Terminal Basics
2. Files and Folders
3. Useful Commands
4. Finding Help
5. Creating and Managing Files
6. Understanding Permissions

Each lesson builds on the previous one.

Take your time.

---

## By the End of This Module

You'll be able to:

- Open the terminal without feeling intimidated.
- Move around the Linux file system.
- Find files and directories.
- Create, copy, move, and remove files safely.
- Understand why Linux protects certain files.
- Feel ready to begin using cybersecurity tools.
