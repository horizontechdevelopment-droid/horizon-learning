"They remember everything."

Learning Tip
!!! tip "Learning Tip"

    Professionals don't become experts by memorizing thousands of commands.

    They become experts by knowing where to find trustworthy answers.

Looking Under the Hood
!!! info "Looking Under the Hood"

    Most Linux commands include their own built-in documentation.

    When you run `man ls`, Linux displays the manual page that was installed alongside the command itself.

Why Professionals Do This
!!! info "Why Professionals Do This"

    Experienced Linux users often read a command's documentation before using unfamiliar options.

    Spending two minutes reading documentation can prevent hours of troubleshooting.

Memory Helper
!!! success "Memory Helper"

    Remember these commands:

    man command      → Read the manual

    command --help   → Quick usage information

    whatis command   → Short description

    apropos keyword  → Search manual pages

Common Beginner Mistake
!!! warning "Common Beginner Mistake"

    Many beginners immediately search random websites and copy commands without understanding them.

    Start with the built-in documentation first, then compare it with trusted resources if you need more information.

Real-World Example
!!! example "Real-World Example"

    Imagine you forget how to use the `cp` command.

    Instead of searching the internet immediately, try:

        man cp

    or

        cp --help

    You'll often find the answer right on your own system.

Progress, Not Perfection
!!! note "Progress, Not Perfection"

    Nobody remembers every Linux command.

    The goal is to become comfortable finding answers, not memorizing every detail.
